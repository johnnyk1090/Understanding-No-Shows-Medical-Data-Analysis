## The question

A missed medical appointment costs a clinic a slot and costs a patient their care. This project runs an **exploratory data analysis** of patients who do not show up for their medical appointments.

## What is inside

- Data visualisation of the factors around a missed appointment
- **Custom classes** for data distributions and plotting
- The public appointments dataset ([`KaggleV2-May-2016.csv`](KaggleV2-May-2016.csv))

## Run it

1. Download `spec-file.txt`.
2. Follow the instructions in `Conda_Virtual_Env.txt`:

```bash
# a new environment from the spec file
conda create --name myenv --file spec-file.txt
# or install the listed packages into an existing environment
conda install --name myenv --file spec-file.txt
```
The full set of environment commands is in [`Conda_Virtual_Env.txt`](Conda_Virtual_Env.txt).

Then open [`medical_appointments.ipynb`](medical_appointments.ipynb).
